# 채용 파이프라인 보드

채용 담당자가 지원자를 채용 단계별로 관리하는 보드입니다.
단계는 `서류검토 - 면접 - 처우협의 - 최종합격 / 불합격` 순이며, 지원자 카드를 단계 간 이동하며 관리합니다.
실제 백엔드는 없고, 프로젝트 내부에 직접 구현한 mock API를 통해 데이터를 읽고 씁니다.

## 스택

- Next.js (App Router) / React / TypeScript
- Tailwind CSS
- 상태 관리 라이브러리 없음 (React 내장 훅만 사용)

## 설치 및 실행

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인합니다.

## 테스트

```bash
npm test
```

순서 계산(`computeOrderBetween`, 정렬 기준점 탐색)과 카드 이동 엔진(낙관적 업데이트, 실패 롤백, 연속 입력 병합, undo)을 UI 없이 검증합니다.

## Mock API

실제 서버 대신 Next.js Route Handler로 직접 구현했습니다.

| 엔드포인트 | 동작 |
| --- | --- |
| `GET /api/candidates` | 전체 지원자 목록 조회 |
| `PATCH /api/candidates/[id]` | 카드를 `beforeId`/`afterId` 사이로 옮기고 단계·순서 저장 |

- 과제 조건에 맞춰 모든 요청에 **200~800ms 지연**과 **15% 실패율**을 적용합니다.
- 카드 순서는 인덱스가 아니라 `order` 값으로 관리하며, 두 이웃의 중간값을 계산해 삽입합니다. 더 쪼갤 수 없으면 해당 단계만 재배정합니다.
- 데이터는 전역 싱글톤으로 보관합니다. 새로고침해도 유지되지만 개발 서버를 재시작하면 초기 상태로 돌아갑니다.

## 키보드 접근성

카드를 마우스로 드래그하지 않고도 키보드만으로 카드 포커스 이동, 단계 이동, 상세 보기, 되돌리기를 사용할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| `Tab` | 보드로 진입 (카드 하나에 포커스가 들어갑니다) |
| `↑` / `↓` | 같은 컬럼에서 이전·다음 카드로 포커스 이동 |
| `←` / `→` | 인접한 컬럼의 카드로 포커스 이동 |
| `Q` | 이전 단계로 카드 이동 (첫 단계에서는 마지막 단계로 순환) |
| `E` | 다음 단계로 카드 이동 (마지막 단계에서는 첫 단계로 순환) |
| `1` ~ `5` | 해당 번호의 단계로 카드 직행 이동 |
| `Space` / `Enter` | 포커스된 카드의 상세 패널 열기 |
| `Ctrl/Cmd + Z` | 가장 최근 이동 되돌리기 |

포커스된 카드는 노란색 테두리로 표시되며, 그 카드가 이동하거나 화면 밖으로 벗어나면 보이도록 자동으로 스크롤됩니다. 위 단축키는 카드에 포커스가 있을 때 동작하므로, 테두리로 표시된 카드가 곧 조작 대상입니다. `Q`/`E`는 양 끝에서 순환합니다. 즉 서류검토에서 `Q`를 누르면 불합격으로, 불합격에서 `E`를 누르면 서류검토로 이동합니다.
