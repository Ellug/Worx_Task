# 채용 파이프라인 보드

채용 담당자가 지원자를 채용 단계별로 관리하는 보드입니다.
단계는 `서류검토 - 면접 - 처우협의 - 최종합격 / 불합격` 순이며, 지원자 카드를 단계 간 이동하며 관리합니다.
실제 백엔드는 없고, mock API(또는 로컬 mock 서버)를 통해 데이터를 읽고 씁니다.

## 스택

- Next.js (App Router) / React / TypeScript
- Tailwind CSS

## 설치 및 실행

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인합니다.

## 키보드 접근성

카드를 마우스로 드래그하지 않고도 키보드만으로 카드 선택, 단계 이동, 상세 보기, 되돌리기를 사용할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| `↑` / `↓` | 같은 컬럼에서 이전·다음 카드 선택 |
| `←` / `→` | 인접한 컬럼의 카드 선택 |
| `Q` | 이전 단계로 카드 이동 |
| `E` | 다음 단계로 카드 이동 |
| `Space` | 선택한 카드의 상세 패널 열기 |
| `Ctrl/Cmd + Z` | 가장 최근 이동 되돌리기 |

현재 선택된 카드는 노란색 테두리로 표시되며, 선택 카드가 이동하거나 화면 밖으로 벗어나면 해당 카드가 보이도록 자동으로 스크롤됩니다. 첫 번째 단계에서 `Q`, 마지막 단계에서 `E`를 누르는 등 이동할 수 없는 방향의 입력은 무시됩니다.

검색어 입력창과 같은 텍스트 입력 영역에 포커스가 있을 때는 위 단축키가 보드 동작으로 전달되지 않습니다.
